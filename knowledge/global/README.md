# Глобальная инженерная база (GLOBAL KNOWLEDGE BASE)

Общие знания для всех объектов: как устроены конструкции, сортаменты, марки стали, нормативы, правила чтения
чертежей и геометрии, примеры монтажных схем. **Фактических координат, отметок и размеров конкретных объектов здесь
нет** — они живут только в проектной базе объекта (SQLite, `object_records` с `object_id`).

Программа эту папку только читает (`src/ai-global-kb.js`); пополняет её сессия разработки после проверки.

## Запись

Обязательные поля: `id` (уникален в каталоге), `status`, `sources`.

- `status`: `confirmed` (подтверждено), `needs_check` (требует проверки), `unknown` (не установлено).
- `sources`: список `id` из `sources.json`; у `confirmed` — хотя бы один.
- Запрещены поля объекта: `project`, `project_id`, `object_id`, координаты (`x_mm`, `y_mm`, `z_mm`, `x0`…).
  Пример с чужими координатами хранится в `examples` с `example_only: true`.

Неподтверждённая запись (`needs_check`, `unknown`) никогда не применяется как точное значение.

Чего нет в таблицах, программа считает по геометрии и помечает «проверить» (`needs_check`, `listed: false`): круг и
квадрат вне списков ГОСТ 2590/2591-2006 («Круг 49»), профильная труба вне таблиц (по размерам с радиусом ГОСТ 32931), гнутый швеллер, которого нет в таблице ГОСТ 8278-83 (например «[155×60×4»: по размерам, без радиуса гиба).

Обозначения Б/Ш/К («I30Ш2») одинаковы в ГОСТ Р 57837 и СТО АСЧМ 20-93; поиск профиля возвращает строку ГОСТ Р 57837 с
полем `standard` — какой стандарт на самом деле указан в спецификации объекта, решает проектная база, не справочник.
