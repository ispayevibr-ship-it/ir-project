# IR Project AI — этап II.2 (версия 1.7.212): подписанный каталог и безопасная загрузка

## Назначение
В меню Настройки → Локальные ИИ-модели подготовлены:
- проверка официального каталога;
- список совместимых доступных версий, размеров скачивания и описаний изменений;
- подтверждение пользователем перед скачиванием, индикация процента и отмена;
- проверка фактического размера и SHA-256 скачанного ZIP;
- дополнительная проверка цифровой подписи содержимого пакета Ed25519;
- отдельное подтверждение установки; предыдущая версия сохраняется.

Код не скачивает ничего автоматически. Проверка каталога только после ручного нажатия «Проверить обновления».
Файл обновления загружается только после отдельного подтверждения пользователя-администратора.
Распознавание КМ/КМД остаётся локальным — файлы чертежей не передаются на сервис обновлений.

## Формат подписанного каталога

По HTTPS с одного доверенного origin публикуется JSON-конверт:

```json
{
 "keyId": "ir-project-models-2026",
 "payload": "<base64 UTF-8 JSON каталога>",
 "signature": "<base64 Ed25519-подписи исходных байт payload>"
}
```

Подписанный payload:
```json
{
 "schema": 1,
 "generatedAt": "2026-10-15T10:00:00.000Z",
 "expiresAt": "2026-10-22T10:00:00.000Z",
 "releases": [
  {
   "modelId": "qwen3-vl-4b",
   "version": "1.0.0",
   "engine": "llama.cpp",
   "url": "https://<официальный-сервер>/qwen3-vl-4b-1.0.0.ir-ai-pack",
   "size": 123456,
   "sha256": "<фактический SHA-256 ZIP архива>",
   "minAppVersion": "1.7.212",
   "notes": "Описание изменений"
  }
 ]
}
```

Этот пример не является реальным релизом: подставлены условные ссылки, размеры и хэши.
Тесты CI генерируют отдельный временный ключ и локальный ZIP, но не публикуют его.

## Проверки защиты
- Только HTTPS без перенаправлений, авторизационных данных в URL и перехода на иной origin.
- Подпись каталога Ed25519 проверяется до использования любых URL и названий версий.
- Истёкший или некорректно датированный каталог отклоняется.
- Ограничение размера каталога, числа версий и размера пакета.
- SHA-256 и полный размер потока загрузки сверяются с подписанным каталогом; файл с ошибкой удаляется.
- Даже прошедший SHA-256 пакет обязан отдельно пройти полную проверку подписанного manifest.json, состава и содержимого.
- Модели и движки не запускаются автоматически по факту загрузки.
- Откат требует отдельной проверки SHA-256 сохранённых файлов.
- Установка и откат в Electron требуют повторного подтверждения пароля администратора.

## Ограничения этого этапа
- **Официальные доверенные ключи и каталог пока не опубликованы и не вписаны в рабочую сборку.**
- Это инфраструктура, которая будет отклонять непроверенные/самодельные файлы. Реальных весов PaddleOCR-VL 1.6 и Qwen3-VL 4B в установщике нет.
- Текущий llama.cpp адаптер предыдущего этапа пока не связан с менеджером моделей. Подключение и тестирование реального runtime — следующий шаг.
- Возобновляемое скачивание частичных файлов (HTTP Range), история обновлений, свободное место перед онлайн-загрузкой и тест реального запуска до активации ещё не выполнены. При отмене незавершённый файл удаляется.
- Исходные чертежи AI по-прежнему не входят в обычный экспорт *.db.
- Нужно проверить окно менеджера на реальной Windows-установке.
- Официальный ключ подписи должен быть сформирован и опубликован отдельно, с надлежащим хранением закрытой части. Нельзя выдавать тестовый ключ за доверенный.
