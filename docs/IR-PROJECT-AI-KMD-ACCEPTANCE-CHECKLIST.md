# IR Project AI — протокол первой приёмки КМД

До отдельной команды ничего не запускать. Проверка выполняется только
на Windows с двумя настоящими установленными подписанными моделями.

## Исходные данные
- Исходный PDF, шифр проекта, номер листа, ревизия и SHA-256 файла.
- Контрольная ведомость отправочных марок и ручная инженерная сверка.
- Версии приложения, Qwen3-VL, PaddleOCR-VL и локальных runtime.
- Аппаратная конфигурация и время обработки.

## Критерии
- Нельзя считать число уникальных обозначений числом экземпляров.
- Нельзя автоматически принимать расхождение массы, количества метизов
  или марки: отправить на инженерную проверку.
- Для каждого результата нужна ссылка на исходный лист; отсутствие
  доказательства — отдельная ошибка покрытия.
- Неоднозначные значения сохраняются как «требует проверки», без догадок.
- Сопоставить суммы по листам, по маркам и по всей ведомости.
- Для комплекта 041-2025 контрольное ранее подтверждённое количество
  экземпляров отправочных марок — 1970; это не число уникальных марок.
  Не использовать это число как замену сверки актуальной ревизии PDF.

## Условия успешного первого запуска
1. Обе модели прошли проверку подписей и SHA-256.
2. Оба локальных движка действительно обрабатывают PDF без интернета.
3. Сохранены результаты, ошибки и ссылки на страницы PDF.
4. Инженер вручную подтвердил либо отклонил извлечённые значения.
5. Все критические расхождения видны до переноса в ведомость и 3D.
