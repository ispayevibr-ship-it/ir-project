# IR Project AI — этап II: локальные ИИ-модели (версия 1.7.211)

## Назначение

В верхнем меню **«Настройки → Локальные ИИ-модели»** добавлен отдельный менеджер для будущих OCR/VLM:
- PaddleOCR-VL 1.6 — OCR, таблицы и распознавание документов.
- Qwen3-VL 4B — визуально-языковой анализ чертежей.

Менеджер показывает установленные и предыдущие версии, размер активной версии, количество локальных версий и статус официального каталога. Проверка обновлений не имитируется: пока каталог не опубликован, кнопка отвечает, что источник официальных обновлений не настроен.

## Офлайн-пакеты: формат .ir-ai-pack

Файл ZIP под собственным расширением `.ir-ai-pack`, состоящий из следующих записей:
- `manifest.json` — подписанные метаданные модели;
- `manifest.sig` — Base64 подпись Ed25519 **неизменённых байт manifest.json**;
- `files/...` — все файлы модели и движка в точности по списку манифеста.

Пример манифеста (значения/хэши только иллюстративные, **не рабочий пакет**):

```json
{
  "schema": 1,
  "modelId": "qwen3-vl-4b",
  "version": "1.0.0",
  "engine": "llama.cpp",
  "keyId": "ir-project-publisher-2026",
  "minAppVersion": "1.7.211",
  "files": [
    {
      "path": "model.gguf",
      "bytes": 12345678,
      "sha256": "<фактические 64 символа SHA-256>"
    }
  ]
}
```

При установке проверяются подпись издателя, заявленный состав ZIP, размеры и контрольные суммы SHA-256. Запрещены обход путей, символьные ссылки, повторы имён файлов, посторонние файлы, неизвестные модели и неподдерживаемые версии. Не допускается установка неподписанного или некорректного пакета.

Сохранение версий: `userData/ir-project-ai/model-manager/models/<model-id>/<version>/`.
Активная/предыдущая версия записываются отдельно в атомарно обновляемый `state.json`.
Сначала пакет распаковывается во временную папку, затем проверяется; только после успешной проверки он становится доступным как отдельная версия. Ранее установленная версия остаётся на диске. Откат дополнительно проверяет её SHA-256.

## Важно: ограничения первого выпуска

**В 1.7.211 нет официальных весов ИИ, доверенного ключа подписи и каталога обновлений.**
Встроенный список доверенных издателей преднамеренно пуст. Пока реальный ключ не утверждён и не опубликован в официальной подписанной сборке IR Project, программа **отклоняет любую попытку установки архива**, даже если архив содержит самостоятельно рассчитанные SHA-256. Тесты CI создают временную пару Ed25519 только для проверки кода; её ключи не используются в рабочей программе.

**Установка модели в менеджер пока не переключает действующий движок распознавания.** Адаптеры PaddleOCR-VL 1.6 и Qwen3-VL 4B разрабатываются следующим этапом. Старый модуль llama.cpp/Qwen3-VL-8B в IR Project не заменяется и не переносится автоматически.

**Проверка работоспособности реальной модели, отображение удалённых версий/размера скачивания, докачка, журнал операций, удаление ненужных моделей и интеграция с GPU** планируются отдельно. Ни один из этих пунктов не заявляется как готовый.

Установка/откат через интерфейс требуют повторного ввода пароля администратора: Electron проверяет его сам и хранит временную авторизацию для конкретного окна. Но существующие фиксированные пароли IR Project следует заменить более защищённой системой сессий до многопользовательской эксплуатации.

Резервная копия SQLite по-прежнему не включает исходные вложения AI. Менеджер не изменяет существующие объекты, схемы, марки и рабочие отчёты.

## Следующий порядок по ТЗ

1. Официальный публичный Ed25519-ключ издателя IR Project, доверенная цепочка распространения, каталог подписанных релизов и совместимость версий.
2. Подключить настоящие офлайн-пакеты PaddleOCR-VL 1.6 и Qwen3-VL 4B без отдельной установки пользователем; проверить CPU/CUDA, RTX 4050 6 ГБ / 16 ГБ RAM.
3. Запуск тестового запроса после установки и только потом переключение на новую модель; откат не должен прерывать обработку документов.
4. Очередь распознавания, OCR и визуальная обработка фрагментов листов PDF с координатами.
5. Объединение проверенных данных в спецификации, марки, метизы и 3D.
