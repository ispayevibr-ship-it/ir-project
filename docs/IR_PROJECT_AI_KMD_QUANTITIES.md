# IR Project AI — учёт количества отправочных марок КМД

**Ветка:** `feature/ir-project-ai-next`. **Статус:** предварительный код. По просьбе пользователя не запускаются тесты, сборка Electron, скачивание моделей и зависимостей, создание установщика. Общую проверку проведём после следующих этапов.

## Назначение

Не смешивать:
- найденные на чертеже **упоминания** обозначения;
- число **уникальных обозначений**;
- число **экземпляров отправочных элементов, указанное в спецификации КМД**.

Количества **не извлекаются из числа упоминаний** и не суммируются по анализам ИИ. Инженер самостоятельно вводит утверждаемое количество из спецификации исходного PDF КМД.

## Что реализовано

### Изолированная ведомость

В модуле IR Project AI на вкладке «Ведомость марок» появляется отдельная таблица «Ведомость отправочных элементов по КМД», не изменяющая производственную `marks` и монтажную схему.

Для одной позиции храним:
- марку (с сохранением различия латиницы/кириллицы);
- шифр и второй шифр;
- **количество экземпляров, шт.** (положительное целое число; для неподтверждённой позиции можно не заполнять);
- источник: документ PDF со статусом КМД, SHA-256 загруженного оригинала, номер листа, позицию спецификации, изменение/ревизию;
- статус: «Требует проверки», «Подтверждено», «Отклонено»;
- комментарий, роль проверившего, время проверки и номер редакции.

Источник выбирается только из загруженных в **этот объект** файлов PDF КМД. Из другого объекта или из КМ файл нельзя указать в качестве основания.

### Формирование суммы

В сводку попадают только позиции со статусом «Подтверждено» и неповреждённой привязкой к исходному документу (тот же SHA-256 и тип КМД). Для одинаковой комбинации «марка + шифр + второй шифр» одновременно не допускаются дубли действующих позиций. При корректировке надо редактировать существующую позицию.

Показываем:
- количество подтверждённых позиций;
- **сумму экземпляров по подтверждённым позициям**, а не по всем КМД в целом;
- число неподтверждённых/отклонённых записей;
- неполноту всей ведомости, пока не проведена сквозная проверка комплекта.

Это пока **не доказанное итоговое количество конструкций объекта**: не все листы/ревизии и позиции могут быть внесены; сумма не используется в готовности объекта.

### Контроль изменений

Редактирование выполняется с проверкой пароля администратора либо инженера в Electron IPC. Применяется контроль `expectedRevision`. Операция изменения записи и добавления строки в `ai-mark-quantity-history` должна проходить одной транзакцией SQLite.

Записи:
- `object_records.section_key="ai-mark-quantities"` — ведомость;
- `object_records.section_key="ai-mark-quantity-history"` — история исправлений.

**Схема SQLite не меняется.** Новые разделы используют существующую таблицу `object_records`. Реестр ИИ не переносит позиции в производственные объёмы.

### Интерфейс

- Просмотр подтверждённых количеств и источников КМД;
- Форма «Добавить позицию из КМД» и изменение существующей позиции;
- Отдельный статус каждой записи;
- Просмотр истории ревизий;
- Валидация целого количества и обязательного номера позиции спецификации;
- Разделение результатов ИИ («упоминания») от подтверждённых экземпляров.

## Ограничения и будущая проверка

- Пока не ведётся самостоятельная сверка двух версий спецификаций КМД (например, изм. 0 / изм. 1). Ведомость требует ручной проверки по последней утверждённой ревизии.
- Не поддержан автоматический импорт позиций из OCR/таблиц; после подключения PaddleOCR/Qwen можно добавлять *предложения*, требующие подтверждения.
- Итоговая масса, метизы, детали, места монтажа и объёмы — следующие этапы.
- Нет автопереноса в рабочую ведомость марок — только после явного согласования и приёмки.
- Не проверялись в этой сессии Windows-установка, база SQLite, работа кнопок, влияние на существующие объекты и реальные КМД. Все интеграционные проверки отложены.
- Пустую ведомость **нельзя** считать нулём проектного количества.
- В проекте 041-2025 ранее была согласована контрольная сумма **1 970 экземпляров отправочных элементов**. Это только контроль для будущей сверки **полного** комплекта. Не проставлять 1 970 без подтверждения по спецификациям и не смешивать с числом уникальных обозначений.
