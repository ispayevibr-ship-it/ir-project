# IR Project AI — интеграция PaddleOCR-VL 1.6

**Статус:** реализован код локального worker API и маршрутизация в процесс распознавания, но **полноценный подписанный OCR-пакет с настоящими весами и Windows exe ещё не изготовлен и не испытан**. Это релизный блокер P0. Реальные веса, PaddlePaddle, DLL и зависимости сейчас не скачивались.

## Обработка PDF

1. IR Project проверяет оригинальный PDF КМ/КМД (SHA-256, редакция), рендерит конкретный лист/область в PNG.
2. \`src/ai-paddle-ocr.js\` требует **установленный подписанный офлайн-пакет** \`paddleocr-vl-1.6\` с двумя локальными деревьями весов.
3. Подписанный исполняемый файл принимает \`--input\`, \`--output\`, \`--layout\`, \`--vision\`. Выполняется локальным дочерним процессом с \`shell:false\`, закрытыми переменными прокси и запретом автозагрузки источников моделей. При отмене процесс завершается и данные не считаются завершёнными.
4. Исходный код worker: \`scripts/ai-paddleocr-worker.py\`. Использует официальный Python API \`PaddleOCRVL(pipeline_version="v1.6", layout_detection_model_dir=..., vl_rec_model_dir=..., use_doc_orientation_classify=False, use_doc_unwarping=False)\`, \`predict()\` и \`save_to_json()\`. Для Windows его нужно собрать **вместе с зависимостями в изолированный exe**, а не запускать системный Python пользователя.
5. Формат ответа \`{"schema":"ir-paddleocr-vl-json-1","complete":true,"text":"...","blocks":[{"type":"table","text":"...","bbox":[x1,y1,x2,y2]}]}\`. Координаты относятся к изображению конкретного листа/области, и до инженерной проверки **не являются координатами конструкции в 3D**.
6. Затем Qwen3-VL 4B получает исходное изображение и ограниченный непроверенный OCR-текст как *данные*, не инструкции. Инженер видит два независимых источника в разделе «Проверка результатов ИИ». Оба сохраняются с моделью, версией и SHA изображения; численность марок и крепёж автоматически **не утверждаются**.
7. Если PaddleOCR отсутствует, очередь помечает задание \`needs_model\`; если OCR вернул ошибку, итог анализа не создаётся.

## Контракт подписанного OCR-пакета

Манифест \`.ir-ai-pack\` должен содержать \`schema:1\`, \`modelId:"paddleocr-vl-1.6"\`, \`engine:"paddleocr"\`, \`version\`, \`keyId\`, \`minAppVersion\`, \`files\` с SHA-256 каждого файла и:

\`\`\`json
{
  "runtime": {
    "protocol": "ir-paddleocr-vl-json-1",
    "binary": "bin/paddleocr-worker.exe",
    "layout": "models/layout",
    "vision": "models/vl"
  }
}
\`\`\`

Все файлы внутри \`models/layout/\` и \`models/vl/\` (в том числе веса, токенизатор и конфигурация) должны быть внесены в подписанный манифест. Менеджер отклоняет пакеты без исполняемого файла или любой из моделей, проверяет Ed25519-подпись и SHA-256 установленных файлов перед распознаванием. Подписанный каталог публикаций и ключи издателя нужно окончательно подготовить отдельно. Размеры, лицензии и совместимость каждой сборки с Windows требуют проверки.

**Изготовление пакета**: на отдельном доверенном компьютере получить официальные веса и исходные компоненты, зафиксировать версии и SHA-256, собрать \`paddleocr-worker.exe\` с PaddleOCR + PaddlePaddle, вложить точные модели и зависимости, подписать архив известным программе ключом Ed25519 и провести проверку чистой установки, отката и работы при физически отключённом интернете. Нельзя распространять случайные неподписанные \`python.exe\` или OCR-бинарники.

## Финальные приёмочные сценарии

- \`scripts/test-ai-paddle-ocr.js\` — отложенный контракт локального взаимодействия, отсутствующего пакета, результата JSON, bbox, SHA-256, отмены и отсутствия сетевых URL; без загрузки и запуска настоящей нейросети.
- Реальный оригинальный PDF КМД: таблица марок, спецификации деталей, метизы/швы, распознанные размеры, имена и числа; сверка по каждому листу инженером.
- PDF высокого разрешения, повёрнутые листы, низкое качество/сканы; ошибки OCR не должны считаться пустой спецификацией.
- Комбинация Qwen и PaddleOCR не считается проверенной до прогона настоящих пакетов и подтверждения их совместимости.

Официальный API PaddleOCR: https://www.paddleocr.ai/main/en/version3.x/pipeline_usage/PaddleOCR-VL.html
