# IR Project AI — монтажная схема по ведомости и КМ/КМД

## Рабочий порядок

1. Создать объект, загрузить ведомость марок и проверить количество
   экземпляров. Включить монтажную схему в нужных видах работ.
2. Сохранить реальную сетку осей и шаги в монтажной схеме.
3. Загрузить PDF планов, фасадов, разрезов и КМД в ИИ.
4. Нажать «Индексировать PDF» для каждого документа.
5. Открыть вкладку ИИ «Монтажная схема» и нажать
   «Построить черновик по чертежам».
6. Получить три группы: возможные размещения, требующие проверки
   и сложные листы для Qwen. Проверить координаты и отметки.
7. Подтвердить группу или отдельные конструкции и открыть
   итоговую общую монтажную схему в 2D / Three.js.

## Принципы обработки

- Текстовый PDF обрабатываем без нейросети. Qwen запускается выборочно,
  по нажатию, для листов с отсутствующим либо повреждённым текстом.
- Нет проверенной оси, отметки или точного соответствия марке —
  нет автоматической расстановки.
- Дубликаты и превышение количества экземпляров блокируют предложение.
- Чертежи отдельных марок без монтажного плана не считаются доказательством
  положения конструкции в здании.
- Никакие инженерные решения, отметки и истории не удаляются автоматически.
- Отключённые разделы деталировки КМД остаются в коде и базе для
  совместимости; удаление возможно после миграции и проверки данных.

## Чего система пока не умеет

Визуальное понимание всего каркаса и полное сопоставление тысяч листов,
индивидуальных чертежей марок, планов и разрезов ещё предстоит разработать.
Qwen обрабатывает сложные листы в очереди, но текущий конвейер не извлекает
из каждого такого результата готовые координаты X/Y/Z без инженера.
Групповое добавление выполняется последовательными сохранениями;
при ошибке количество сохранённых экземпляров указывается явно.
