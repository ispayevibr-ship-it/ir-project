# IR Project AI — этап 4, версия 1.7.210

## Реализовано
- Просмотр первого или выбранного листа PDF как PNG внутри IR Project AI, масштаб «По ширине / 100%».
- Реальный рендер PDF.js 6.4.299 + @napi-rs/canvas 1.0.10 в отдельном Node Worker без облака и без нейросети.
- Строгие лимиты: PDF до 48 МиБ, до 80 страниц, 90 секунд на лист, 3,5 млн пикселей на изображение, максимальная сторона 2400 px.
- Оригинал PDF сохраняется. Результат просмотра не добавляется в основную монтажную схему.
- Для индексированных PDF при реально запущенной локальной модели — распознавание выбранного листа и сохранение ответа в SQLite как «Требует проверки инженера», с номером листа, SHA-256 источника и исходным ответом.
- CI-тесты реального PDF→PNG с проверкой PNG, источника, номера листа и запрета автоматического подтверждения.

## Чего пока нет
- Официального дистрибутива весов Qwen3-VL и llama.cpp: НЕ входит в установщик. Без него предпросмотр работает, кнопка ИИ отключена.
- Нет OCR без модели, нет пространственных координат распознанных деталей, нет гарантированной точности геометрии и узлов.
- Рендер листа A0/A1 ограничен ~3,5 Мп; для мелких надписей нужны тайлы высокого разрешения.
- Исходные документы AI не входят в текущую *.db резервную копию. Сохраняйте оригиналы отдельно.
- Для многопользовательского режима необходимо усилить проверку прав в Electron IPC.
- Требуется практический тест на Windows/Electron с реальным комплектом КМД.
